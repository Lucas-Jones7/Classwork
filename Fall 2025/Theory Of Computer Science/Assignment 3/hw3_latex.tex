\section{Problem 01}
\noindent
Prove if the following language is regular or not. \(A=\{ w |~ w \text{ contains the same }\\ \text{number of 01 and 10 as substrings.}\}\). For example, \(\epsilon, 1110101, 10001\) are in the language but \(1010\) is not. 

Hint: If a language is regular, then there exists a DFA or NFA that recognizes the language. If language is not regular then you can use pumping lemma to prove that it is non-regular.


\section{Problem 02}
Prove that following language is not regular.

\[B = \{1^n |~n \text{ is a prime.}\}\]

\section{Problem 03}
Suppose you want to prove that the language
\[C = \{www: w \in \Sigma^*\}.\]
is not regular using the pumping lemma.

You assume that the pumping length is \(p\) and choose the string \(s=0^p0^p0^p\) as a candidate that might violate the lemma. 

Is this a suitable choice for proving that \(C\) is not regular. Explain your reasoning.

\section{Problem 04}
Design context-free grammars for the following languages.
\begin{enumerate}
    \item \(A = \{ a^nb^m~|~n\neq 2m\}\), where \(\Sigma = \{a,b\}\).
    \item \(B = \{ w~|~w\text{ contains at least three }1s\}\), where \(\Sigma = \{0,1\}\).
    \item \(C = \{ w~|~w=w^\mathcal{R}\text{, that is, }w\text{ is a palindrome}\}\), where \(\Sigma = \{0,1\}\).
    \item \(D = \{ a^nb^m~|~n = 3m\}\), where \(\Sigma = \{a,b\}\).
\end{enumerate}


\section{Problem 05}

\section{Problem 06}

\(A \rightarrow BAB ~| ~B~|~ \epsilon\)

\(B \rightarrow 00 ~|~ \epsilon\)
