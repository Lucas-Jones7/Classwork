\section{Problem 01}
\noindent
Provide a implementation-level description of TM that decides the following language: \(L = \{\text{Same number of 0's and 1's}\}\). 

When I say implementation level description, what I mean is for you to give an algorithm on how the Turing machine moves its head and way it is stored data when it decides the given language. Refer the implementation-level description  related to \(A = \{0^{2^n}| n \geq 0\}\). (You do not need to draw the Turing machine)

\section{Problem 02}
Let \(\Sigma = \{a, b\}\). We define the language \(EVEN_{TM}\) as follows:

\[EVEN_{TM} = \{<M> | M \text{ is a TM and } L(M) \text{ contains only strings of even length.}\}\]

Prove that \(EVEN_{TM}\) is undecidable.

\section{Problem 03}

\section{Problem 05}
Find a match in the following instance of the Post Correspondence Problem.
\[\left[ \frac{ab}{abab} \right], \left[ \frac{b}{a} \right], \left[ \frac{aba}{b} \right], \left[ \frac{aa}{a} \right]\]

\section{Problem 06}
Show that \(ALL_{DFA} = \{\langle A\rangle\} | \text{$A$ is a DFA and $L(A) = \Sigma^*$}\) is decidable.

\section{Problem 07}
Show that \(A_{\epsilon CFG} = \{ \langle G\rangle | \text{$G$ is CFG that generates $\epsilon$}\}\) is decidable.

\section{Problem 08}
Let \(\mathcal{B}\) be the set of all infinite sequences over \(\{0,1\}\). Show that \(\mathcal{B}\) is uncountable using proof by diagonalization.
