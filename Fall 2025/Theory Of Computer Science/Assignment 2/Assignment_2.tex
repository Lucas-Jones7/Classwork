\section{Problem 01}
\noindent
Give state diagrams of DFAs (finite automaton) that recognizes the following languages. Consider the alphabet is \(\Sigma = \{0,1\}\).
\begin{enumerate}
    \item \(A = \{ \epsilon, 0\}\)
    \item \(B = \{ w : w \text{ has length at least 3 and its third symbol is a 0}\}\)
    \item \(C = \{ w \text{ starts with 0 and has odd length, or starts with 1 and has even length}\}\)
\end{enumerate}


\section{Problem 02}
Give state diagrams of NFAs with the specified number of states recognizing each of the following languages. In all parts, the alphabet is 
 \(\Sigma = \{0,1\}\) 
 \begin{enumerate}
     \item The language \(\{\epsilon\}\).
     \item The language \(0^*1^*0^+\) with three states.
     \item The language \(A = \{w : w \text{ contains an even number of 0s, or contains exactly two 1s}\}\) with $6$ states.
 \end{enumerate}
